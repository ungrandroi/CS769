# 实验配方

## 目的和主要功能

保存 工具调用图记忆项目的当前默认字段与可选择的图记忆、模型、编辑及投喂配方。

## 适用范围

正式命令通过 `base/config.py` 读取 JSON；单次修改后的生效配置随运行保存。

`_base.json` 提供公共配置片段，其他文件按 `extends` 相对路径继承。普通字典递归合并，采样和接入点配置整体替换，最后补齐 `ExperimentConfig` 的缺省字段。现有文件内容与迁移前一致。

配方与参数说明见 [模型与图记忆方法](../doc/models.md)。旧路径 `src/cs769/configs/` 通过相对链接读取这里。
