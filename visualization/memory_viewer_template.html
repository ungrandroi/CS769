    数据来源与读法
    
    
      
  • 数据来自 qwen27b_experiment/tasks/ 的原始请求与响应记录，没有重新推理。得分为官方 BFCL 整任务评分。
    • 
      
  • 三种方法共用同一段 Qwen 第 1 轮。两种 Compact 分支回放这段首轮来恢复环境，第 2 轮用户输入前把旧历史换成一条图记忆，之后的新消息照常追加，不再压缩。
    • 
      
  • 文件环境：用官方 GorillaFileSystem 逐条重放工具调用得到。每次输出与记录一致，每轮结束时的目录树与 BFCL 状态日志一致。
    • 
      
  • 图视图：用该批次 source_code/ 中的构图代码，对整段可见历史重建。替换点之前的节点与实际发送的图一致（实线）。替换点之后的部分在实验中以原始消息形式追加，这里按同一规则画出，仅作对照（虚线 / 斜纹）。
    • 
      
  • 工具定义的 token 数：用服务端同一 chat template 和本地 Qwen tokenizer，把同一条请求分别带工具、不带工具渲染并计数，两者之差即工具成本；渲染总数与服务端 usage 逐 token 一致。
    • 
      
  • 上下文文本：每次调用实际发送的输入消息。较长的工具返回在页面上截断显示，并标出原长度。
