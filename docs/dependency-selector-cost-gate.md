# Optional dependency-selector cost gate

Study options:
- selector_gate: dependency-selector-horizon-v1
- selector_editor: prune_dependency_slice
- selector_interface: shared-packet-short-decision-v2

Without this option previous study behavior is unchanged.
Only completed graph/current request are inputs. Existing reference, identifier
and error guards remain. Quoted references matching a candidate or its producing
call protect the candidate through result_of. Shared payloads are not excluded.
Absence of an edge is never proof of irrelevance.

The paired lossless view is the baseline. Free singleton and capped-combined
probes estimate marginal rendered savings after sharing. Probes are hypothetical,
not semantically approved edits. The existing selector context is retained;
this version does not omit evidence that may carry unresolved obligations.
Maximum selector output is 256 tokens. Estimated input includes schema/framing.

Paid review is admitted when an optimistic candidate probe can repay within
4 future requests. Reports show 1/2/4-request scenarios. The horizon is a
development admission assumption, not actual future usage or a prediction.
After selection, actual selector token usage and selected-memory length are
checked again. If the selected edit cannot repay within 4 requests, it falls
back to paired lossless memory. Already spent selector tokens still count.
Original selections and dry probes remain archived.

Graph deletion, model-facing representation and official eval are unchanged.
Selector and continuation requests share one locked budget. Report total tokens
including editing, task outcomes, new tool calls and true information loss.
A no-op is not a lossy-edit success; small selected cohorts do not establish
population-level non-inferiority.
